# Valundersökningen 2006

## Källa

Oscarsson, Henrik och Sören Holmberg. 2008. *Regeringsskifte*. Valforskningsprogrammet, Göteborgs universitet.

Den tillhandahållna bilden visar **tabell 2.1**, ”Vart gick 2002 års väljare? (procent)”, med **radprocent** och antal svarande per 2002-kategori. Cell- och kolumnantal samt sidnummer saknas.

Enligt tabellkommentaren kommer uppgiften om partival 2002 för halva urvalet från minnesuppgifter 2006 och för andra halvan från paneldata 2002; valdeltagandet har kontrollerats mot röstlängderna. Källans *soffan* återges som **Icke-röstare** och *bl* som **Blankt**; sista raden avser ej röstberättigade 2002.

Tryckta radprocent summerar till **98–101 %** trots angiven total 100 %. Varje rad normaliserades därför med **sin egen procentsumma**, multiplicerades med sitt publicerade antal och avrundades med **största restens metod** (lika rester: kolumnordning). Radmarginalerna är exakta; kolumnmarginalerna är beräknade, inte separat kalibrerade.

Cellantalen är **inte verifierade individsvar**: avrundade 0 % kan dölja svarande, och små rader (särskilt SD och Övr 2002) är känsliga för avrundning. Se [metodanteckningarna](../METOD.md).
