# Valundersökningen 2014

## Källa

Oscarsson, Henrik. 2016. *Flytande väljare*. *Demokratistatistik*, rapport 21. Stockholm: Statistiska centralbyrån.

De tillhandahållna bilderna saknar sidnummer och visar:

- **Tabell 2**, ”Vart tog 2010 års väljare vägen 2014?”: **radprocent** och radantal.
- **Tabell 3**, ”Varifrån kom 2014 års väljare?”: **kolumnprocent** och kolumnantal. Trots bildens kommentar ”radvis” står 100 procent under varje kolumn i raden *Totalt*.

Tabellerna anger Svenska valundersökningar 2010 och 2014 samt Europaparlamentsvalsundersökningen 2014 som källa. Analysen sammanför **1 868** svarande från Valundersökningen 2014 och **1 609** från Europaparlamentsvalsundersökningen 2014. Partival 2010 bygger på panel- eller minnesuppgifter; materialet är alltså inte enbart riksdagsvalsundersökningen 2014.
